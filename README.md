# The Lost World

An illustrated dinosaur learning adventure at [dino.surf](https://dino.surf).

Explore eighteen painted regions, meet sixty dinosaurs, investigate cited fossil evidence, compare metres and feet, and settle into an illustrated listening library. Fifty-eight chapters have Peter narration; ten new creature stories are currently illustrated text.

This repository distributes Windows portable previews and showcase films. The application source and personal journals are not included here.

Choose a release below for the Windows ZIP, checksums, installation notes, and the five-minute narrated film. Extract the complete Windows ZIP before launching the application. The preview is unsigned and has passed software and package checks; native Windows, assistive-technology, human listening, and clean-machine acceptance remain outstanding.

The browser showcase stores its own discoveries on your device. It does not read or synchronize a Windows journal. The Windows application's bundled collection works offline.

Paintings and fables are imagined reconstructions and original fiction. Scientific evidence includes sources and distinguishes supported observations, interpretation, and unknowns. Narration uses an AI-generated Peter voice.
